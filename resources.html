Ресурсы

Материалы, которые помогали нам в разработке: от партнёрских каталогов до документации фреймворков.

Организация-партнёр

  • Трансмашхолдинг (ТМХ) — основной источник данных о моделях подвижного состава, характеристик и превью.
  • РЖД (ОАО «Российские железные дороги») — информация об эксплуатации и парке.
  • Метровагонмаш — каталог вагонов метро и спецификации.

Документация и статьи

  • Three.js Documentation — официальная документация по рендерингу, загрузчикам и контролам.
  • Vue 3 Guide — Composition API, реактивность, SFC и TypeScript-интеграция.
  • GLTF Overview — справочник по формату GLTF/GLB и PBR-материалам.
  • Vite Documentation — настройка сборки, плагины и оптимизация.

Онлайн-курсы

  • Three.js Journey (YouTube-конспекты) — основы 3D в браузере, освещение, шейдеры.
  • Vue 3 Composition API (Udemy) — углублённая работа с реактивностью и компонентами.
  • Современный учебник JavaScript — справочник по языку и DOM.

Инструменты

  • GitHub — хостинг репозитория, Issues, Actions CI/CD.
  • Jest — фреймворк для модульного тестирования с поддержкой ESM.
  • Blender — подготовка и оптимизация 3D-моделей, настройка анимаций.
  • Vite — инструмент сборки и dev-сервер для фронтенда.

Статьи по теме

  • Habr: WebGL и Three.js для начинающих — обзор возможностей библиотеки с примерами кода.
  • Habr: Vue 3 + TypeScript в production — практические советы по строгой типизации.
  • MDN: WebGL API — справочник по низкоуровневой графике в браузере.

Видеоматериалы

  • YouTube: Как работает GLTF — короткое объяснение формата и его преимуществ.
  • YouTube: Vue 3 Composition API за 1 час — краткий курс для быстрого старта.

Мы также записали собственное демо-видео работы конфигуратора, которое доступно по запросу у команды.
